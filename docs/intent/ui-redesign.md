# UI Redesign — Confirmed Intent

_Confirmed via `interview-me` on 2026-05-18._

## Outcome
Redesign the frontend top-to-bottom so the app reads as a credible B2B company to investors, energy/grid customers, and consultants — not a side project.

## User
External evaluators — investors, prospective enterprise customers, and energy consultants seeing the app in demos and pitch settings.

## Why now
Pipeline is warming (investor + customer conversations). The current UI's blue-heavy dark theme and indie-grade polish undercuts the credibility of what the product actually does.

## Success
A first-time viewer's gut reaction in a demo is "this is a real company." Concretely:
- Unified design system across every screen.
- Neutral dark theme with a single restrained green accent (replacing the cobalt-blue palette).
- Modern-SaaS aesthetic — reference register: Linear, Vercel, Watershed.
- Consistent typography, spacing, components, and page chrome top-to-bottom.

## Constraint
No hard deadline this week. The bar is quality, not speed. Approach:
1. Audit the current frontend (read-only).
2. Produce a locked design direction document (palette, typography, spacing scale, references, screen inventory).
3. Redesign one hero screen as a full-fidelity vertical slice for approval.
4. Only after approval, roll the locked system across the rest of the app.

## Out of scope
- Light theme (explicitly deferred — revisit after dark theme lands).
- New product features or backend changes.
- Information-architecture changes beyond what is required for visual coherence (consistent nav, page chrome, light reorg of homepage/dashboard — not a from-scratch rethink).
